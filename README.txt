IDENTIA DEMOKRATIS — website prototype

Open index.html in a browser. The page is a static, responsive prototype.
- assets/id-logo.png is the logo image supplied by the user.
- Image areas are intentionally placeholders; replace them with generated images later.
- News headlines are sample layout text, not canon or real events.
- The contact address uses example.invalid and must be replaced before publishing.
- Main colors: navy #0B2942, party blue #0077BD, cool gray #F0F4F7.
- The site is currently English-first; translate/adjust copy as desired.

Publishing notes:
- The HTML includes a robots noindex/nofollow meta tag to ask search engines not to index the page. This is not an access restriction and is not guaranteed to hide the site from every search engine.
- The site is clearly labelled as a fictional worldbuilding project.
- GitHub Pages on a free personal account generally requires a public repository; the site itself is publicly accessible. Do not upload private information.
